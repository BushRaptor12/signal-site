# Facebook graphic downloads

The admin graphic maker is available at `/admin/facebook`. The story selector labels each published story as **Has image** or **No image**. It creates a square 1200 × 1200 preview with a navy-and-gold treatment, the Beacon mark, a date, and `readthebeacon.news`. Horizontal and vertical crop sliders let an admin position the source photo before previewing. An uploaded image is used only for the graphic and does not change the story's image on the site.

After reviewing the preview, choose **Download HD image · 2400 × 2400** to save a high-resolution PNG. No Facebook developer app, Page token, or server publishing variables are needed.
